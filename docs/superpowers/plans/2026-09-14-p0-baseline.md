### Task 1: Make Vitest use jsdom `localStorage` under Node 26

**Files:**
- Create: `frontend/src/test-setup.ts`
- Modify: `frontend/angular.json` (the `test` target `options`)
- Test: `frontend/src/app/core/auth/auth.service.spec.ts` (existing, currently failing)

**Interfaces:**
- Produces: a global test setup file that later plans extend (P1a adds Material test providers here).

- [ ] **Step 1: Reproduce the failure**

Run:
```bash
timeout 90 npx --prefix frontend ng test --watch=false --include='**/auth.service.spec.ts' 2>&1 | sed 's/\x1b\[[0-9;]*m//g' | grep -E "×|✓|Tests |ExperimentalWarning"
```
Expected: `ExperimentalWarning: localStorage is not available because --localstorage-file was not provided.` followed by 9 `×` lines.

- [ ] **Step 2: Create the setup file**

`frontend/src/test-setup.ts`:
```ts
/**
 * Node >= 25 exposes an experimental `globalThis.localStorage` that is inert
 * unless `--localstorage-file` is passed. It shadows jsdom's implementation and
 * every test touching storage fails. Re-point the globals at jsdom's window.
 */
const w = globalThis as unknown as { window?: Window & typeof globalThis };
if (w.window) {
  for (const key of ['localStorage', 'sessionStorage'] as const) {
    Object.defineProperty(globalThis, key, {
      value: w.window[key],
      configurable: true,
      writable: true
    });
  }
}
```

- [ ] **Step 3: Register it in angular.json**

In `frontend/angular.json`, change the `test` target to:
```json
"test": {
  "builder": "@angular/build:unit-test",
  "options": {
    "tsConfig": "tsconfig.spec.json",
    "buildTarget": "frontend:build:development",
    "runner": "vitest",
    "setupFiles": ["src/test-setup.ts"]
  }
}
```

- [ ] **Step 4: Verify the auth spec passes**

Run:
```bash
timeout 90 npx --prefix frontend ng test --watch=false --include='**/auth.service.spec.ts' 2>&1 | sed 's/\x1b\[[0-9;]*m//g' | grep -E "Tests |Test Files"
```
Expected:

If the process does not exit within 90 s, kill stale workers (see Global Constraints) and rerun once.

- [ ] **Step 2: Fix the visited check**

`Set.prototype.add` returns the Set (always truthy), so `if (seen.add(next))` never filters. Replace the `walk` closure in `lineageOf` with:

```ts
  const walk = (edges: Map<string, Set<string>>) => {
    const queue = [personId];
    while (queue.length) {
      for (const next of edges.get(queue.pop()!) ?? []) {
        if (seen.has(next)) continue;
        seen.add(next);
        queue.push(next);
      }
    }
  };
```
